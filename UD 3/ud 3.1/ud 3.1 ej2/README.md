## Diferencia entre `position: sticky` y `position: fixed`:
- **`position: sticky`**: El elemento actúa como un elemento normal (`static`) hasta que la ventana de visualización (viewport) llega a una posición de desplazamiento determinada (en este caso `top: 0`). A partir de ese momento, se queda "pegado" en la pantalla mientras se hace scroll dentro de su contenedor padre, volviendo a su sitio si se sale de él.
- **`position: fixed`**: El elemento se fija de forma permanente respecto a la ventana del navegador, ignorando el flujo normal de la página y el scroll. Si cambiamos el menú a `fixed`, este flote se desvincularía por completo del documento y se superpondría de manera intrusiva al contenido que hay debajo (tapando la parte superior de las secciones), por lo que requeriría añadir un margen superior (`padding-top`) al cuerpo de la página para compensarlo.
