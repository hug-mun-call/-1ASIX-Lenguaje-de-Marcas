# UD2.1 - Ejercicio 1

## Preguntas teóricas

### ¿Cuál de las tres formas es la más cómoda si tuvieras que cambiar el color del título en 10 páginas?
La hoja de estilos externa (`estilos.css`). Al estar enlazada en todas las páginas, solo necesitas modificar una línea de código en el archivo CSS para actualizar el diseño en el resto del sitio web de forma automática.

### ¿Por qué se desaconseja la primera (estilos inline)?
Porque mezcla el contenido HTML con el diseño, lo que dificulta el mantenimiento del código. Si quieres hacer un cambio global, tendrías que modificar elemento por elemento en cada archivo, lo que genera errores y pérdida de tiempo.
